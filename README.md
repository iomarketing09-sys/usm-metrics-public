# Universe Sent Me Metrics — Public Pages

This public repository contains only policy pages and a TikTok URL-verification signature file for the **Universe Sent Me Metrics App**.

It must never contain API keys, OAuth client files, access tokens, raw analytics, financial records, personal data, or content from Bam in a Can, Firma Bordados, or any unrelated brand.

## Public routes

| Route | Purpose |
| :--- | :--- |
| `/terms/` | Terms of Service for the local read-only metrics app. |
| `/privacy/` | Privacy Policy for the local read-only metrics app. |
| `/privacy/tiktok*.txt` | TikTok verification signature file, added only after TikTok generates it for this URL prefix. |
